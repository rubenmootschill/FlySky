You'll notice that in the sample files, the API key is only stored in
the backend and then hashed via an AJAX call to a server-side PHP script

key hashing from PHP into a different backend language as needed. It is
not recommended to store or expose the API key client side, as if it is
ever stolen or misused we might need to disable it.
